# FluxoContábil — V11 simplificada para apresentação ao orientador

Esta edição é baseada na V10, preservando a correção de acesso (modo Visitante e contas locais).

**O que foi ocultado na demonstração:** item de menu do bate-papo, acesso à tela de mensagens e chamadas por navegação, e avisos secundários de conclusão exibidos no painel. Os códigos da comunicação continuam no pacote apenas para preservação; não são parte do roteiro de avaliação.

**O que permanece disponível:** visão geral, empresas, equipe, checklist, lançamentos, conferências, alertas, justificativas editáveis, auditoria, competências, fechamento, roteiro de teste e avaliação local. Alertas contábeis permanecem visíveis.

**Limitações importantes:** esta é uma PWA local com dados fictícios, não integrada ao backend Django. Os alertas estatísticos demonstrativos não comprovam execução dos modelos de ML. Login e armazenamento são locais, não autenticação segura. A avaliação local da PWA não envia respostas ao Google Forms. Nunca digite dados pessoais, contábeis ou de clientes reais.

**Como publicar no GitHub Pages:** envie os arquivos deste ZIP à raiz do repositório existente, substituindo os anteriores. Preserve o arquivo `.nojekyll`. O cache do service worker foi atualizado para V11; após publicar, atualize a página (em alguns casos, feche e reabra o aplicativo instalado) e teste os três fluxos: checklist, conferências, alertas e justificativas. Publicação não é automática.

**Envio ao orientador:** use o link público somente após verificar que a versão V11 foi publicada. O Forms de avaliação deve ser compartilhado somente após alinhamento metodológico e ético com o orientador.
