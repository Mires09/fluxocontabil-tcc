# FluxoContábil — protótipo acadêmico (PWA)

Demonstração acadêmica com dados fictícios. Não inserir informações contábeis reais.

## Publicação no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie **os arquivos extraídos** deste ZIP para a raiz do repositório (não envie o ZIP como arquivo isolado).
3. Em Settings > Pages, escolha Deploy from a branch; selecione `main` e `/(root)` e salve.
4. Depois que a implantação terminar, acesse `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
5. No navegador compatível, use o menu para instalar o aplicativo ou adicionar à tela inicial.

O projeto é estático e não utiliza autenticação real, IA real nem backend compartilhado. Dados de uso ficam no armazenamento local do navegador e não são enviados ao orientador.

## Arquivos
- `index.html`: página de entrada
- `styles.css`: estilos
- `app.js`: lógica demonstrativa
- `manifest.webmanifest`: configuração PWA
- `sw.js`: cache offline
- `icon-192.png`, `icon-512.png`: ícones
- `.nojekyll`: evita processamento Jekyll no GitHub Pages
